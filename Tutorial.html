Website Project

How This Website Was Created

About Me | Favorite Games | Favorite Shows | Contact Me | Website Project

Step 1: Create the HTML Files

I created several HTML pages for my website, including an About Me page, a Favorite Games page, a Favorite Shows page, a Contact Me page, and this Website Project page.

Step 2: Upload Files to GitHub

After creating my HTML files, I uploaded them to a GitHub repository. GitHub stores the files online and keeps track of changes made to the project.

Step 3: Publish with GitHub Pages

GitHub Pages allows a repository to be turned into a live website. After enabling GitHub Pages and making sure my main page was named index.html, GitHub generated a public website link.

What I Learned

  • How to create webpages using HTML
  • How to add navigation links between pages
  • How to include images and forms
  • How to improve accessibility and SEO
  • How to publish a website using GitHub Pages
